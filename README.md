# Human Fallback Layer

This project serves as a "human fallback layer" for AI, allowing individuals to offer their services for tasks that AI cannot complete. The application connects users with tasks that require human intervention, providing a platform for collaboration between AI and human capabilities.

## Features

- **Dashboard**: Users can view their tasks and statistics.
- **Task Management**: Users can browse, accept, and manage tasks that require human input.
- **User Profiles**: Each user has a profile displaying their information and task history.
- **API Integration**: The application includes API routes for managing tasks and user data.

## Getting Started

To get started with the project, follow these steps:

1. **Clone the repository**:
   ```
   git clone <repository-url>
   ```

2. **Navigate to the project directory**:
   ```
   cd human-fallback-layer
   ```

3. **Install dependencies**:
   ```
   npm install
   ```

4. **Run the development server**:
   ```
   npm run dev
   ```

5. **Open your browser** and navigate to `http://localhost:3000` to view the application.

## Folder Structure

- `src/app`: Contains the main application files, including pages and API routes.
- `src/components`: Contains reusable components used throughout the application.
- `src/lib`: Contains utility functions for database and authentication.
- `src/hooks`: Contains custom hooks for managing application state.
- `src/types`: Contains TypeScript types and interfaces.
